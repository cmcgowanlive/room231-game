THE MYSTERY OF ROOM 231 — FREE WEBSITE STARTER

1. Open ORGANIZER_SETUP.html on your computer. Upload game-data.json, assign E01–E20 to their approved stations, paste approved evidence, the final code and Evidence 21 letter, then download the updated game-data.json. Replace the old file.
2. Create a free GitHub account. Create a PUBLIC repository named room231. Upload index.html and game-data.json from this folder to the repository root.
3. In repository Settings > Pages choose Deploy from branch, main, /(root), Save. Wait for the published https://USERNAME.github.io/room231/ address.
4. Open PRINT_QR_CODES_AFTER_PUBLISHING.html, enter the published address, generate 16 starting codes and 22 shared station codes, and print.
5. TEST ALL ROUTES ON PHONES BEFORE PRINTING. Use fresh browsers to test.

IMPORTANT LIMITATIONS: This is a prototype, NOT guest-ready until evidence/location assignments, content and code are approved. Progress is stored in each browser only; it does not sync across devices or provide secure access control. A manual fallback allows advancing without physically scanning; this is intentional to prevent staff assistance queues. Do not rely on the client-side code gate to prevent determined cheating. The QR print utility uses a free external QR image service and needs internet access. No hosting account has been created or published by the assistant.
